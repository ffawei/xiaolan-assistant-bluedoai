# 小蓝助手 Blue（BlueDoAI）：跨应用资料汇总

当一项工作涉及网页、安卓应用和本地文件，可以把它们放进同一个任务说明。先指定资料范围，再约定最后交付什么。

## 给小蓝的任务

```text
请把我指定的网页、安卓应用内容和本地文件整理成一份资料表。

先确认每种来源的访问方式、允许处理的范围、必要的账号登录和输出目录。安卓应用通过指定的MuMu实例操作，明确ADB设备；仅访问我指定的内容。

逐项提取标题、正文或摘要、来源和原始日期。找不到的信息留空并说明，不根据猜测补写。

按我给出的主题分类。重复资料保留来源关系；相似但内容不一致的资料单独列出，不自动当成重复删除。

将附件保存到项目目录，制作可编辑的Excel或CSV索引。需要脚本时，把脚本和使用说明一并留下。

最后检查附件路径、来源和索引是否对应，列出未完成项及原因。不要替我向外发送、发布或提交资料。
```

## 检查结果

随机选择几条记录，回到原始来源核对。对资料冲突、日期缺失和未完成项逐项处理，再将成果用于后续工作。

本页是任务模板。使用前应根据实际应用、权限和文件格式调整，并先完成少量样例检查。
