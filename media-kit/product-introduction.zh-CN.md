# BlueDoAI 与小蓝助手产品介绍

## 公司与产品名称

公司：成都蓝色精英信息技术有限公司  
平台：BlueDoAI 模型与算力服务平台  
工具：小蓝助手 Blue（BlueDoAI）

BlueDoAI：统一接入 AI 模型，按量使用算力。  
小蓝助手：智能体处理不了的工作，找小蓝助手。

## 公司短版

BlueDoAI 提供 AI 模型与算力服务，统一管理模型接入、API Key 和用量，按实际用量计费。配套小蓝助手 Blue（BlueDoAI）处理工业工艺与研发资料、复杂脚本和跨应用任务；企业可咨询本地化部署、培训与技术支持。

## 公司中版

BlueDoAI 由成都蓝色精英信息技术有限公司运营，为个人、开发者和企业提供 AI 模型与算力服务。用户可在模型广场查看人民币价格，使用统一 API 接入应用，在控制台管理 API Key、余额和用量。

配套的小蓝助手 Blue（BlueDoAI）面向需要动手完成的复杂任务：整理工艺与研发资料、编写并运行脚本、处理图片，在软件、网页与本地文件之间接续工作。小蓝助手已有多家制造业上市公司客户案例。工具本体免费；托管模型按量计费，本地化部署、培训与技术支持按项目约定。

## 公司长版

BlueDoAI 以模型与算力服务为核心，提供统一模型接入、API Key 和用量管理。个人创作、开发项目与企业应用可按实际任务选择模型，在官网核对可用型号、人民币售价和计量规则。文本模型与视频生成分别按对应接口接入。

小蓝助手 Blue（BlueDoAI）是配套的 Windows 执行型 AI 智能体。用户提供资料、明确目标并授权后，小蓝可拆解多步骤工作、编写并运行复杂脚本，在支持的软件和网站之间继续执行，将文件、脚本、数据与处理记录保存在项目目录中，便于复核和修改。

在工业工艺与研发工作中，小蓝可以参与工艺文件整理、试验记录分析、需求版本核对和数据处理。PS 图片处理、视频与文字归档、跨应用资料汇总，也可按具体任务开展。通过 ADB 连接 MuMu 安卓模拟器，可把安卓应用中的步骤与 Windows 上的文件处理接起来。

小蓝助手已有多家制造业上市公司客户案例。企业可围绕自己的资料、岗位任务和既有流程咨询应用方式、本地化部署、实施培训与技术支持。涉及工艺参数、设备操作、安全和产品性能的结论，由负责的专业人员审核确认。

小蓝助手工具本体免费，不因下载、安装或工具使用单独收取软件使用费。用户可以接入自有模型 API；本地模型的接口与功能适配以当前版本说明为准。使用 BlueDoAI 托管模型时按实际用量计费，可用型号与最终售价以实时模型广场为准。企业专项服务的交付范围和费用按有效合同确定。

## English description

BlueDoAI provides AI model access through a unified API, with API key management, usage tracking and usage-based pricing. Its companion Windows agent, Xiaolan Assistant Blue (BlueDoAI), handles authorized multi-step work involving industrial process and R&D documents, scripts, Photoshop images and supported applications. It can connect to MuMu through ADB to link Android tasks with Windows workflows.

Xiaolan Assistant has customer use cases with multiple publicly listed manufacturing companies. The tool itself is free to use; hosted model usage is billed separately. Local model compatibility depends on the current client and interface. Enterprise deployment, training and technical services are available by project agreement.
