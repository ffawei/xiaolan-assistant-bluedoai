# 文件都发齐了，为什么还交不了差？小蓝助手的资料交接方法

项目群里传来一句“材料都在文件夹里了”，接手的人打开一看：报价有三个版本，图片有两套，说明文档里引用的附件还停留在上周。文件不少，工作却没法往下走。

这是一种常见的交接困境。下面用一个模拟任务说明处理方法，不对应某个客户的实际项目。

先问下一位接手的人要做什么

假设接手者需要整理一份对外材料。真正需要的不是把文件再压缩一遍，而是弄清哪些已经确认、哪些仍在修改、哪些只能当参考。

任务负责人先确定资料范围，再给每份文件标明名称、版本、来源和状态。找不到状态的地方留作待确认项，不让AI按照文件名或修改时间替负责人拍板。文件保存得晚，并不一定意味着它已经获批。

让小蓝先做一张能打开文件的索引

给小蓝助手 Blue（BlueDoAI）的第一步任务，可以是扫描指定目录，列出文件路径、格式和已有版本标记。原文件保留，只在独立工作目录中生成整理结果。

索引表中的链接要逐项检查。某份文档引用了附件，就把附件也列进去；读不到的文件写明原因。这样交出去的表格才有用，接手者能顺着它找到材料，而不是拿着另一份需要解释的清单。

差异只写到能核对的程度

两份报价或两版说明有差异时，列出差异位置和对应来源。数字不一致，保留两边的值；单位没有写清楚，标记缺失；涉及选择哪一版的问题，交回负责人确认。

如果文件很多、规则又重复，可以让小蓝编写并运行脚本，批量提取信息或整理命名。脚本和运行说明一起留下，下次交接就有可以修改的起点。

遇到需要人工处理的环节，列出来

跨应用任务不一定一次走完。有的资料需要登录后才能看，有的图片需要进PS处理，有的业务状态只能由项目负责人确认。把这些环节列入待办，说明缺什么、卡在哪里、下一步由谁接手。

任务范围允许且当前环境支持时，小蓝可以继续操作相应应用；需要人工登录、授权或业务判断时，保留进度，等确认后再接着做。

交接时检查三个结果

一是资料能打开，二是结论能找到来源，三是未完成项有人接手。至于节省了多少时间，应当记录整理和复核的实际耗时，再与原有做法比较。
