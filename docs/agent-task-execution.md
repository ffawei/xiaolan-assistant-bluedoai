# AI给了方案，剩下的操作谁来做？试试小蓝助手

方案写得很完整，工作却还留在桌面上。

表格需要合并，图片要进PS修改，研发记录散在几个文件夹里。问AI，它能列出步骤；真正动手时，仍要有人打开软件、找文件、运行脚本，再把结果收齐。

**卡住的，往往就是这些具体操作。**

小蓝助手 Blue（BlueDoAI）是一款自研的Windows执行型AI智能体。它面向需要动手完成的工作，在用户授权的范围内编写并运行复杂脚本，接续多个应用和网站上的任务，把成果留在可以检查、继续修改的项目目录中。

智能体处理不了的工作，找小蓝助手。下面用几个任务示例，看看怎样把一项卡住的工作交给它。示例用于说明方法，不对应具体客户的项目复盘。

## 一份研发汇总，麻烦可能在表格之外

假设需要整理一轮试验资料：参数在Excel里，照片按日期存放，临时调整写在另一份说明中。要交一份汇总，先得弄清每张照片、每组数字对应哪个批次、哪一版工艺。

直接让AI“分析一下”，资料关系不一定就能对上。

可以把任务交给小蓝：读取指定目录，整理批次与版本索引，再按已经确认的字段规则汇总数据。每条结果附上来源文件，照片保留对应编号。发现单位不一致、记录缺失或版本冲突，单独列出来。

数量多、规则重复时，让它编写脚本处理；规则尚未确定的部分，留给负责人确认。脚本、汇总表和异常清单一起交付，后面补一批资料，也有可以继续修改的起点。

**研发资料整理的价值，要在复核时看得见：一条结论能否找到原始记录？**

小蓝助手已有多家制造业上市公司客户案例。企业可以围绕工业工艺与研发资料、试验记录和岗位任务咨询具体应用。工艺参数、设备安全与性能结论，仍由专业人员审核。

## 图片改好了，整项任务还要接着做

再看一个产品资料任务：处理一批图片，导出适合官网和演示文稿的版本，按产品编号整理，补齐图片索引。

PS导出成功，只完成了其中一段。

原图与修改图有没有对应？文件名会不会冲突？横版图放进页面后有没有裁掉主体？下一位同事能不能顺着索引找到可编辑文件？这些也属于交付。

小蓝可以结合当前PS环境和可用操作方式处理图片，再接着完成命名、目录整理和资料汇总。安排任务时，把尺寸、用途、保留格式与输出目录说清楚；遇到无法处理的素材，保留原因和位置。

如果资料在安卓应用里，也可以在授权范围内，通过ADB连接MuMu模拟器，把支持的应用操作接到Windows工作中。具体能否执行，要看应用、接口、登录状态和内容使用权限。

## 给小蓝一项能验收的工作

第一次使用，不必把整个岗位一次交出去。选一项反复要做、又能看清结果的任务，更容易发现它适不适合自己的工作。

比如把“帮我整理资料”，改成下面这份任务：

> 整理我指定目录中的本轮试验资料，保留原文件。按已确认的批次和版本建立索引，汇总字段与单位一致的数据。把缺失项、冲突和无法读取的文件单独列出。先处理一小批给我检查，确认后继续。结果、脚本和运行说明放进新的交付目录。

要求可以写得朴素，但范围要清楚。哪些目录能读、哪些文件能改、遇到什么情况需要停下来确认，都应在执行前说明。

验收时，打开结果看一遍。核对来源、抽查数据，再看看未完成项有没有写清楚。任务需要接续时，前一轮留下的文件和记录就是下一轮的起点。
