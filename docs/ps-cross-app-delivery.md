# 图片改好了，任务却没交完：小蓝助手怎样接续PS与资料整理

一张图改好了尺寸，导出也没报错，但同事拿到文件后仍要追问：原图是哪张？对应哪段文字？可编辑文件放在哪里？

图片处理完成，不代表整项素材任务已经交清楚。下面用一个模拟的资料整理任务说明怎样安排这些环节，不代表客户项目效果。

从交付目录倒着安排

假设要整理一批已经获得使用授权的图文素材。最终目录需要保留原始文件、处理后的图片，以及一张对应表。表里写明素材编号、来源、原文件路径和导出文件路径。

这份表的作用很直接：别人看到成图时，能够找到原件；发现文字或尺寸需要调整时，也能找到对应的可编辑文件。不要等图片全部改名之后，再回头猜它们之间的关系。

PS要改什么，先用少量样例说明

给小蓝助手 Blue（BlueDoAI）的要求应包括尺寸、格式、命名方式和参考效果。需要保留可编辑文件，就明确列入交付要求；只需要导出图片，也要说明保存位置。

用户自行安装并合法使用PS。先在当前软件环境里试做少量样例，核对文字、主体、边缘和尺寸。确认操作适用以后，再处理更多文件，原素材保留一份。

重复规则可以交给脚本

图片改名、清点数量、生成索引等规则明确的步骤，可以让小蓝编写和运行脚本。输出目录中同时保存脚本和运行说明，方便再次使用。

碰到重名文件，先列出冲突；导出失败，记录对应素材；找不到原图，标记缺失。不要为了让文件数量看起来齐全，就用不相关的文件补上。

安卓端的资料怎样接到电脑

有些授权素材需要先从安卓应用中整理。小蓝可以通过ADB连接指定的MuMu安卓模拟器，在支持的应用和允许的操作范围内执行任务，再与Windows端的文件处理接起来。

先确认模拟器实例、应用登录和内容使用权限。下载采用应用允许的方式，需要人工确认的环节停下来交接。材料到了电脑以后，继续沿用来源编号，避免跨一次应用就丢掉一次对应关系。

最后检查一整项工作

图片能打开、尺寸符合要求，索引能定位到文件，未处理项有原因；需要继续修改的内容，有原始素材或可编辑版本可用。满足这些条件，接手者才知道能用什么、还差什么。

小蓝助手面向Windows上的复杂脚本、PS图片处理和跨应用任务，也可参与工业工艺与研发资料整理。它适合处理那些需要实际操作、步骤又不止一步的工作，具体能力取决于当前软件环境、接口和授权范围。
